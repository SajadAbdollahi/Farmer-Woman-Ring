# Farmer Woman — In the Ring

این پروژه نسخهٔ Rigged شخصیت Farmer Woman از Grab3D را در یک رینگ بوکس نمایش می‌دهد. دکمهٔ «مشت» اسکلت مدل را حرکت می‌دهد و شخصیت سپس به حالت اولیه برمی‌گردد.

## اجرا

به Node.js نسخهٔ 20.19 به بالا (یا 22.12 به بالا) نیاز دارید.

```bash
npm install
npm run dev
```

نمایشگر از فایل `public/models/farmer-woman-rigged.glb` که در مخزن قرار دارد استفاده می‌کند. دستور `npm run dev` آدرس محلی Vite را نمایش می‌دهد. دکمهٔ «وارد کردن GLB» هم برای باز کردن فایل محلی در مرورگر در دسترس است.

## کنترل‌ها

- چرخش دوربین: درگ با ماوس/لمس
- زوم: اسکرول ماوس/پینچ
- دکمهٔ «نمای شخصیت»: کادر نزدیک‌تر و نمایش تمام‌قد
- دکمهٔ «نمای رینگ»: دید باز از رینگ
- دکمهٔ «وارد کردن GLB»: بارگذاری فایل اصلی از کامپیوتر
- مشت: دکمهٔ «مشت» یا کلید Space. این حرکت برای اسکلت نسخهٔ Rigged Farmer Woman ساخته شده است.

## منبع و مجوز

- مدل دقیق: https://grab3d.com/models/characters/farmer-woman/
- دانلود مستقیم نسخهٔ Rigged: https://grab3d.com/dl/farmer-woman-rigged/farmer-woman-rigged.glb
- انتشار مدل توسط Grab3D با مجوز **CC0 1.0**.
- مدل در مرکز رینگ قرار می‌گیرد. حرکت مشت با چرخش مفصل‌های مدل اجرا می‌شود و فایل GLB در زمان اجرا تغییر نمی‌کند.

## فایل‌ها

- `src/main.js`: بارگذاری GLB، قرارگیری دقیق در مرکز رینگ، کنترل‌های رابط کاربری
- `src/punch.js`: حالت‌های بالاتنه و بازو برای حرکت مشت روی اسکلت مدل Rigged
- `src/ring.js`: صحنهٔ رینگ، نور، دوربین، سایه‌ها و OrbitControls
- `src/style.css`: رابط کاربری
- `scripts/fetch-assets.mjs`: دانلود و بررسی صحت GLB اصلی

## بررسی

کد جاوااسکریپت با `npm run check` قابل بررسی است و خروجی تولیدی با `npm run build` ساخته می‌شود.
