# Farmer Woman — In the Ring

این پروژه **همان شخصیت اصلی Farmer Woman از Grab3D** را بدون هیچ تغییر در مدل، لباس، کلاه، صورت، مو، متریال یا بافت‌ها در یک رینگ بوکس نمایش می‌دهد. نه دستکش بوکس به او اضافه شده، نه ریگ یا انیمیشن بوکس استفاده می‌شود. کاراکتر کاملاً ثابت است؛ تنها می‌توان دوربین را چرخاند یا زوم کرد.

## اجرا

به Node.js نسخهٔ 20.19 به بالا (یا 22.12 به بالا) نیاز دارید.

```bash
npm install
npm run dev
```

هنگام `npm run dev` اسکریپت، مدل رسمی **Static / Full quality / GLB** را از Grab3D دریافت و در `public/models/farmer-woman.glb` ذخیره می‌کند. نسخهٔ اصلی ~23 MB است و بافت‌های 4K همراه دارد. سپس Vite اجرا می‌شود و آدرس برنامه در ترمینال نمایش داده می‌شود (معمولاً http://localhost:5173/).

اگر دانلود خودکار در شبکهٔ شما کار نکرد، **به‌صورت دستی** وارد صفحهٔ زیر شوید:

https://grab3d.com/models/characters/farmer-woman/

گزینه‌های **Static → Full quality → GLB** را انتخاب و فایل دریافتی را به مسیر `public/models/farmer-woman.glb` کپی کنید. سپس صفحه را رفرش کنید. راه سریع‌تر: از دکمهٔ **وارد کردن GLB** داخل برنامه فایل دانلودشده را باز کنید؛ این کار نیاز به جابه‌جا کردن فایل ندارد.

در صورت تمایل می‌توانید از دستور `npm run assets` جداگانه برای دانلود استفاده کنید.

## کنترل‌ها

- چرخش دوربین: درگ با ماوس/لمس
- زوم: اسکرول ماوس/پینچ
- دکمهٔ «نمای شخصیت»: کادر نزدیک‌تر و نمایش تمام‌قد
- دکمهٔ «نمای رینگ»: دید باز از رینگ
- دکمهٔ «وارد کردن GLB»: بارگذاری فایل اصلی از کامپیوتر
- هیچ انیمیشنی اجرا نمی‌شود. برای اینکه وضعیت مدل **دقیقاً مثل فایل اصلی** باشد، pose اصلی آن دست نخورده است.

## منبع و مجوز

- مدل دقیق: https://grab3d.com/models/characters/farmer-woman/
- دانلود مستقیم نسخهٔ اصلی: https://grab3d.com/dl/farmer-woman/farmer-woman.glb
- انتشار مدل توسط Grab3D با مجوز **CC0 1.0**.
- مش‌ها، پوشاک، متریال‌ها و اسکلت مدل در کد تغییر داده نمی‌شوند. فقط مدل در مرکز رینگ قرار گرفته و در صورت نیاز اختلاف واحدهای مختصات اصلاح می‌شود تا روی کف بایستد.

## فایل‌ها

- `src/main.js`: بارگذاری GLB، قرارگیری دقیق در مرکز رینگ، کنترل‌های رابط کاربری
- `src/ring.js`: صحنهٔ رینگ، نور، دوربین، سایه‌ها و OrbitControls
- `src/style.css`: رابط کاربری
- `scripts/fetch-assets.mjs`: دانلود و بررسی صحت GLB اصلی

## بررسی

کد جاوااسکریپت با `npm run check` قابل بررسی است و خروجی تولیدی با `npm run build` ساخته می‌شود. چون در محیط آماده‌سازی این پروژه دسترسی شبکه برای دریافت باینری GLB و نصب پکیج‌ها وجود نداشت، نمایش نهایی مدل در مرورگر امکان تست عملی نداشت. فایل ZIP به‌صورت عمدی حاوی جایگزین ساختگی/مدل مشابه نیست: فقط **همان مدل اصلی** پس از دانلود وارد صحنه می‌شود.
